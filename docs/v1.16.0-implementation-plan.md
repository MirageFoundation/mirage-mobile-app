# v1.16.0 Mobile Implementation Plan

This plan maps every change from the v1.16.0 backend guide to concrete files and tasks in the mobile codebase.

---

## Overview

v1.16.0 replaces the 4-tier system (Free/Basic/Pro/Premium → indices 0-3) with a 3-tier system (Free/Subscriber/Agent → levels 0/1/10), renames "moderators" to "agents", adds new profile fields (biography/avatar/banner/flair), introduces the Agent overlay system on posts, adds 3 new API endpoints, requires usernames for all transactions, and changes upgrade level values.
